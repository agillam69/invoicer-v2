# Progress Report — 2026-06-23

Current app version: **v1.35.4** (cross-refresh + ledger + enrolled count + enrol-from-students)

## Completed

- **Cert budget split (Pending / Live)** — Pool cards show both balances. Live
  excludes spends linked to scheduled courses; Pending includes everything.
  (`data_store.py: get_pool_stats_live`, `students_tab.py` pool cards)

- **Course prerequisites system** — `PrerequisiteManagerDialog` links course
  types (one required before another). "Prerequisites…" button in courses tab.
  Stored in `prerequisites.csv`. (`courses_tab.py`, `data_store.py`)

- **Prerequisite validation** — On enrolment, `check_prerequisites` verifies
  completion, scheduled dates, and uploaded evidence; warns with override
  option. (`data_store.py: check_prerequisites`, `courses_tab.py: _add_enrolment`)

- **Student document upload** — Upload / Open / Delete documents per student in
  Student Detail. Files copied to `documents/` dir, metadata in
  `student_documents.csv`. Upload dialog captures type, linked course type, and
  description. (`students_tab.py`, `data_store.py`)

- **Document → prerequisite evidence link** — Documents tagged
  `prerequisite_evidence` with a linked course type are recognised by
  `check_prerequisites`.

- **Window size increase** — Default geometry `1200x900`, minsize `1000x750`
  to prevent scrolling in Create Invoice tab. (`invoice_gui.py`)

- **Generate Draft button** — Saves a `.docx` version of the invoice (same
  content, not recorded in the system) via `python-docx`.
  (`invoice_gui.py: _generate_draft`, `_create_docx`)

- **Word wrap in PDF & DOCX** — PDF table cells now use `Paragraph` objects so
  long descriptions wrap; DOCX table has explicit column widths.
  (`invoice_gui.py: _create_pdf`, `_create_docx`)

- **Help guide export** — On first run the bundled `help_guide.html` is copied
  to the data directory; opened from there afterwards. Linked in Help menu.
  (`invoice_gui.py: _open_help_guide`, `InvoiceGenerator.spec` datas)
