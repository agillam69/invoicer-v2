1. Getting Started

Invoice Generator is a Windows desktop application for managing invoices, training courses, student enrolments, financial ledger, and certificate budgets — all in one place.

First Launch

  1. Double-click Invoice Generator v1.34.exe to start the application.
  2. On first run, a login screen appears. Default credentials: username admin, password Admin.
  3. The application creates all required data files automatically in the same directory as the executable.
  4. Go to Edit → Settings to configure your business details, GST rate, and payment terms.
Tip: All dates in the application use DD/MM/YYYY format. When typing dates, entering dd/mm/yy will auto-correct to full 4-digit year.

2. Login & Users

Logging In

Each time the application starts, you are prompted for a username and password. The current user is displayed in the status bar at the bottom.

Managing Users

  1. Go to Users → Manage Users… from the menu bar.
  2. Add new users, change passwords, or delete user accounts.
  3. All user activity is logged in the audit trail.
Note: The default admin account has username admin and password Admin. Change this immediately after first login.

3. Creating & Managing Invoices

Create Invoice Tab

Create a New Invoice

  1. Navigate to the Create Invoice tab.
  2. Invoice number and date are pre-filled. Adjust the due date if needed.
  3. Select a client from the dropdown or enter a name and address manually.
  4. Add line items by selecting from the Service catalogue or typing a description, quantity, and unit price.
  5. Check Taxable for items that attract GST.
  6. Click Add Item to add the line. Repeat for multiple items.
  7. Review the subtotal, GST, and total at the bottom.
  8. Click Save Invoice — a PDF is generated and saved automatically.

Create Invoice from Course

  1. Click ⚡ From Course… in the Invoice Details panel.
  2. Pick a course from the list.
  3. Line items are auto-populated from the course's enrolments and cert costs.
  4. Review and adjust items, then save.

Edit a Line Item

Double-click any line item in the items table to load it back into the edit form. Make changes and click Add Item (now labelled "Update Item") to save.

Remove a Line Item

Select a line item and click Remove Selected.

Tip: Use Edit → New Invoice or Ctrl+N to clear the form and start fresh.

5. Managing Clients

Clients Tab

The Clients tab shows all clients with their contact details, number of invoices, and total billed.

Add / Edit Clients

  1. Click Manage Clients (or Edit → Manage Clients…).

6. Ledger (Income & Expenses)

Ledger Tab

Track all financial transactions (non-invoice income and expenses) in a general ledger.

Add a Ledger Entry

  1. Go to the Ledger tab.
  2. Fill in: Date, Type (in/out), Category, Amount, Description, Reference, and Notes.
  3. Click Add Entry.

Edit an Existing Entry

Double-click a row in the ledger tree to load it into the form for editing. The button changes to "Update Entry".

Filtering & Date Ranges

  • Use the Search box to filter by any text.
  • Filter by Type (in/out) or Category.
  • Set From / To dates, or use quick-select buttons: This Week, This Month, Last Month, This Year, All.

Import & Export

  • Paste from Clipboard — paste tab- or comma-separated data.
  • Import from CSV… — import ledger entries from a CSV file.
  • Export to CSV… — save all ledger entries to a CSV file.
Tip: The running balance summary (total in / out / net) is shown above the ledger tree and updates live as you filter.

7. Student Management

Students Tab → Student Register

The Student Register is the main view showing all students and their enrolments in a flat list.

Add a Student

  1. Click Add Student in the toolbar.
  2. Fill in the student's details: first name, last name, email, phone, USI, work group, manager, emergency contact.
  3. Optionally link an enrolment at the same time.
  4. Click Save.

Inline Editing

Double-click any editable cell directly in the register tree to modify it in-place. Combo dropdowns appear for status fields, date pickers for date fields.

Filtering

  • Filter — free-text search across all columns.
  • Status — filter by enrolment status (enrolled, completed, etc.).
  • Show Deleted — toggle to reveal soft-deleted records.

Bulk Actions

  • Bulk Edit… — select multiple rows, then set a field (work group, status, cert issued, etc.) to the same value.
  • Mark Completed — mark selected enrolments as completed.
  • Mark Cert Issued — mark cert issued with today's date.

Import Options

  • Import XLSX… — import from an Excel student tracker.
  • Import CSV… — import legacy flat CSV format.
  • Paste Students — paste clipboard data (tab/comma separated).
  • Export CSV… — export student records.

Merge Duplicates

  • Merge Duplicates — auto-find and merge records with the same name/email.
  • Manual Merge… — pick two specific students to merge, choosing which field values to keep.

8. Student Detail View

Students Tab → Student Detail

The Student Detail sub-tab shows comprehensive information about a single student and all their enrolments.

Opening a Student's Detail

  1. In the Student Register, select a student row.
  2. Click Open Detail (or right-click → "Open Student Detail").
  3. The Student Detail tab opens showing the student's info header and enrolment tree.

Student Info Header

Displays: name, email, phone, USI, status, work group, manager, emergency contact, and notes.

Enrolment Tree

All enrolments for this student (including deleted) are listed with:

  • Course name and date
  • Cost (parenthesised if not charged)
  • Enrolment status, attendance, cert issued, cert date
  • Cancellation notes and general notes

Editing Enrolments

  • Inline edit — double-click status, attendance, cert issued, cert date, or notes to edit in-place.
  • Right-click — context menu with Set Status ▶, Set Attendance ▶, Set Cert Issued ▶ submenus.
  • Edit Enrolment… — opens the full enrolment dialog for comprehensive editing.
  • Edit Student… — opens the student record dialog to update personal details.

Enrolment Actions

  • Delete Enrolment — soft-delete (restorable). Reverses any budget spend.
  • Restore Enrolment — un-delete a previously deleted enrolment.
  • Mark Completed — change status to "completed" for selected enrolments.
  • Mark Cert Issued — set cert issued to "yes" and cert date to today.
Data Consistency: All edits in the Student Detail view are saved through the central DataStore and apply system-wide. Changes automatically refresh in both the Student Register and any other views (Courses, Reports).

11. Certificate Budget Tracking

Cert Budget Tab

Track certification budget pools — money allocated for cert costs vs. actual spend.

Managing Budget Entries

  1. Click Add Top-Up to record funding added to a pool.
  2. Click Add Spend to manually record a cost against a pool.
  3. Select an entry and click Edit Selected or Delete Selected.

Budget Pools

  • Click Manage Pools… to create, rename, or delete budget pools.
  • Each pool shows a balance card with: top-up total, spent total, remaining balance.
  • Balances update automatically when enrolments are created or status changes trigger budget auto-posting.

Automatic Budget Posting

When an enrolment status changes:

  • Status → enrolled/completed/no show: cert cost is automatically deducted from the pool.
  • Status → pending/cancelled/withdrawn: any previous deduction is reversed.
  • Deletions also reverse any auto-posted spend.

Filtering

Filter budget entries by search text, type (topup/spend), pool name, and date range.

15. Data Management & Backups

Automatic Backups

When enabled in Settings, the app silently creates timestamped zip backups at the configured interval. Old backups are automatically pruned.

Manual Backup

Tools → Backup Now creates an immediate backup.

Export All Data

Tools → Export All Data… creates a complete zip archive of all data files, invoice PDFs, and logs — with a manifest for easy identification.

Import Data

Tools → Import Data… restores from a previously exported zip. You can choose to overwrite existing files or only import missing ones.

Reload from Disk

Tools → Reload All from Disk (or F5) re-reads all data files and refreshes every tab — useful if files were edited externally.

Migration from Older Versions

Tools → Migrate from V1.8 folder/zip… imports data from an older format.

Windows Startup

The application can be configured to launch at Windows logon via the registry Run key. When launched this way, it uses a --delayed flag to wait briefly before showing the window.

17. Troubleshooting

App won't start / crashes immediately

Check the app.log file in the data directory for error details. Ensure all data CSV files are not locked by another program (e.g., Excel).

Data not appearing after import

Press F5 to reload all data from disk. Check that the data directory setting points to the correct folder.

Invoice PDF not generated

Ensure the invoice output directory exists and is writable. Check Settings → PDF save mode and directory.

Budget not updating automatically

Budget auto-posting only occurs on status transitions. If you manually edited the CSV, use F5 to reload. Verify the course has a cert_cost set and is assigned to a budget pool.

Duplicate students appearing

Use Merge Duplicates (auto) or Manual Merge… to consolidate records. The system matches on exact email or first+last name.

Date format issues

All dates should be entered as DD/MM/YYYY or DD/MM/YY (auto-corrected). Internal storage uses YYYY-MM-DD but display is always DD/MM/YYYY.

Recovering deleted records

Deleted students and enrolments are soft-deleted (marked with a flag). Enable "Show Deleted" in the register, then use Restore to recover them.

Viewing logs

Go to Reports → Audit Log for a full history of data changes, or Reports → App Log for technical messages.

Data Safety: Never edit CSV files directly while the application is running. Use the built-in export/import or close the app first. Always keep backups enabled.
